# Troubleshooting

| Problem | Action |
|---|---|
| Mac blocks the launcher | **System Settings → Privacy & Security → Open Anyway**. |
| Windows protects your PC | **More info → Run anyway** for your trusted Jobcu download. |
| Helper installation fails | Check the internet connection and start the launcher again. |
| Browser does not open | Keep the launcher running; open `http://127.0.0.1:8765`. |
| Engine is not answering | Reopen the launcher if its terminal was closed. |
| Older version cannot close | Close other Jobcu terminal windows, then start again. |
| Key is rejected | In Settings, replace it with the complete key, save and test. Keep it out of chat/screenshots. |
| Model is unknown | **Load model list** and choose one supported by your account. |
| AI rate limit | Wait for Jobcu's retry; check your provider's allowance if it is exhausted. |
| Research unavailable / condition not checked | Check model/account research support. A connection test alone cannot prove it. See [key setup](getting-your-keys.md). |
| Few or no jobs | Read **Search details** for failed sources/limits; try a wider place, longer window or more job types. |
| App repeatedly stops | Report the error in the local project chat without private inputs or raw logs. |
| GitHub download page is unavailable | Use the [public repository](https://github.com/UtkuDenizAltiok/jobcu); no invitation is needed. |

For shared reports, use fictional examples and remove keys, documents, queries, results and
account details from screenshots. Public GitHub issues must contain no personal data.
