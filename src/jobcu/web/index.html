          Settings

          AI provider

          Choose one provider and one model. Jobcu uses them to read your documents, compare job ads and check information online where supported. A provider supplies the AI; a model is the AI version. See "Set up your keys" in the README for help, and check your provider's prices before searching.

          Your API key is saved only on this computer and sent only to its provider. After saving it, choose a model and test the connection below.

          Advanced AI settings (optional)

          One model is enough for a basic setup. Change these options only for a specific need. Saving keeps your choices even when this section is closed.

          Custom API

          Use your service's documented format. The provider address is the base address, without /chat/completions, /responses or /messages. A compatible format does not guarantee every model supports Jobcu's structured answers.

          Responses and Messages send medium using their native controls. A rejected reasoning control stops the request; Jobcu will not quietly remove it. Enabled thinking and high/max mappings are not measured equivalents of medium.

          Interpretation model

          Leave empty to use your main model for your CV, cover letter and location request too. An override also handles estimates and online research when no separate research provider is chosen. Every AI step defaults to medium.

          Online research

          Use your main AI when it supports web search. Choose a separate provider only if you need one for online checks. Necessary text goes to each chosen provider, with separate charges and the same Jobcu usage limits.

          Research provider API key

          This uses the same saved key as that provider's main AI option. Each connection test checks generation, not online search permission.
